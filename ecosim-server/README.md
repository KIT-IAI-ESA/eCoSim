# ecosim-server

The eCoSim server. It runs a co-simulation step by step, passes the values between the clients and stores the results in PostgreSQL/TimescaleDB or in JSON lines files.

See the [eCoSim documentation](https://ecosim.easimov.com/docs) and the [options of `ecosim-server`](https://ecosim.easimov.com/docs/reference/command-line#server).
