# ecosim-hpc

Runs the eCoSim server and its clients on a Dask cluster, for example on an HPC cluster with SLURM and dask-mpi.

The command is `ecosim-hpc`, usually started with `mpirun`. `ecosim-hpc --help` lists its options.

See the [HPC cluster guide](https://ecosim.easimov.com/docs/guides/hpc-cluster) of the eCoSim documentation.
