# Guidelines

The guidelines for this repository live in `AGENTS.md` and `.agents/`, shared by all AI
agent tools.

Read, in this order:

1. `AGENTS.md` — entry point and the hard rules
2. `.agents/guidelines/general.md`
3. `.agents/guidelines/python-coding.md`
4. `.agents/guidelines/repository.md`

Procedures for recurring tasks are in `.agents/skills/<name>/SKILL.md`; read the matching
one before running commands. `.agents/skills/orientation/SKILL.md` is the map of the
codebase.
