# General AI Agent Guidelines

## Communication
- Ask clarifying questions if anything is unclear before taking action
- Confirm requirements and details when ambiguous
- Keep responses short and precise
- Avoid unnecessary explanations or summaries
- Use direct, concise language

## Task Management
- Create and maintain `agent-todo.md` with all tasks
- Update task status as you progress (pending, in_progress, completed)
- Follow the todo list systematically
- Mark tasks complete only after verification
- Add newly discovered tasks to the list
- Don't invent tasks
- Focus on your current task

## Best Practices
- Prefer simple solutions over complex ones
- Break large tasks into smaller, manageable steps
- Verify assumptions with the user
- Report progress on multi-step tasks
