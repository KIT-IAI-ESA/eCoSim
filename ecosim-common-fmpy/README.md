# ecosim-common-fmpy

Code shared by the eCoSim clients for FMI 2.0 and FMI 3.0 models, which run the models with fmpy: the `fmu_file` setting, the `--validate-fmu-file-only` option that only checks the FMU file and the interfaces of the `.fmc` file, and a fix for a threading problem in lxml.

See the [architecture page](https://ecosim.easimov.com/docs/development/architecture#subprojects) of the eCoSim documentation.
